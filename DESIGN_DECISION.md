# Smakota Bot — Дизайн WebApp: Стратегія та Обґрунтування

## Чому Stripe — найкращий вибір для більшості

**Stripe вважається золотим стандартом веб-дизайну.** Чому?

1. **Універсальність** — їхній дизайн заходить ЛЮДЯМ. Не технічним спеціалістам, а звичайним людям. Він чистий, зрозумілий, не напружує.

2. **Довіра** — фіолетово-синя гама підсвідомо викликає відчуття надійності. Stripe обробляє мільярди доларів — якщо такий дизайн використовується для грошей, то для їжі він точно підійде.

3. **Типографіка** — легкий шрифт (weight 300) робить текст повітряним, не тисне. Люди читають швидше і з меншим зусиллям.

4. **Простір** — багато білого простору. Їжа на фото дихає, не затиснута рамками.

## Але для Смакоти — Stripe + Notion + оранжевий

```
Stripe (80%):   структура, типографіка, довіра, чистота
Notion (15%):   теплі відтінки замість холодних
Оранжевий (5%): фірмовий колір #f65e07 — апетит
```

## Що робить інтерфейс "найкращим для всіх"?

1. **Ієрархія** — очі самі ведуть по сторінці: фото → назва → ціна → кнопка "додати"
2. **Мінімум кліків** — ти маєш замовити за 3 тапи: категорія → страва → додано
3. **Зрозумілість без інструкцій** — користувач має інтуїтивно розуміти що робити
4. **Консистентність** — всі елементи виглядають як один цілий
5. **Фідбек** — кожна дія має реакцію (кнопка натиснулась, кошик оновився)

## Як Stripe це робить?

Головний секрет Stripe — **одна товщина шрифту (weight 300) для всього тексту**, навіть для заголовків. Це анти-тренд: всі роблять жирні заголовки, а Stripe робить легкі. Це створює відчуття "нам не треба кричати, щоб нас почули" — впевненість, люкс, довіра.

Для їжі це працює ідеально: фото страв стають головним елементом, а текст не відволікає.
