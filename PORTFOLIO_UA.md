# Професійне портфоліо: Telegram-бот для доставки їжі "Smakota"

## Опис проекту

**Smakota** - це сучасний Telegram-бот для оформлення замовлень доставки їжі, розроблений для малого бізнесу у сфері харчування. Це мій перший комерційний проект, який демонструє мої навички розробки ботів, роботи з користувацьким досвідом та інтеграції різних функцій в єдину систему.

## Функціональність

### Основні можливості:
- 🍕 **Розгалужене меню** з 6 категоріями страв (понад 100 позицій)
- 🛒 **Система кошика** з можливістю додавання/видалення товарів
- 💰 **Автоматичний підрахунок** загальної суми замовлення
- 📝 **Оформлення замовлення** з ім'ям, контактом, адресою та коментарем
- 📱 **Сповіщення адміністратору** про нові замовлення
- 📊 **Зручний інтерфейс** з кнопками та інлайн-меню

### Технічні особливості:
- Повна інтеграція з Telegram API
- FSM (Finite State Machine) для управління станами користувача
- Система управління замовленнями
- Збереження даних про замовлення
- Обробка помилок та відновлення після них

## Технології

- **Python 3.12**
- **pyTelegramBotAPI** - основна бібліотека для роботи з Telegram API
- **python-dotenv** - для безпечного зберігання конфігураційних даних
- **JSON** - формат для зберігання даних меню
- **ООП та процедурний стиль** - для забезпечення читабельності коду

## Архітектура

Бот побудований за модульним принципом:
- Окремі функції для роботи з меню, кошиком, замовленнями
- Чітке розділення логіки обробки повідомлень та callback-запитів
- Система станів для управління процесом оформлення замовлення
- Логування всіх дій для подальшого аналізу

## Користувацький досвід

- Інтуїтивно зрозумілий інтерфейс
- Чітка навігація між розділами
- Зручна система підтвердження замовлень
- Можливість скасування замовлення на будь-якому етапі
- Повідомлення з підсумком замовлення перед оформленням

## Результати

Цей проект:
- Демонструє мої навички розробки ботів для Telegram
- Показує розуміння принципів UX/UI
- Відображає здатність створювати функціональні рішення для бізнесу
- Підходить для масштабування та подальшого розвитку

Smakota - це повноцінний продукт, який може бути використаний для реального бізнесу. Він створений з урахуванням найкращих практик розробки, зручності використання та можливостей подальшого розширення функціоналу.
