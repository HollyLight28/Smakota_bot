# Проєкт: Telegram-бот для сервісу доставки "Smakota"

## 1. Резюме проєкту

**"Smakota"** — це повнофункціональний Telegram-бот, розроблений для автоматизації прийому замовлень у закладах харчування. Бот надає клієнтам зручний інтерфейс для перегляду меню, додавання страв у кошик та оформлення замовлення, а адміністратору — можливість миттєво оновлювати меню через Google Таблицю.

Цей проєкт демонструє здатність створювати надійні, ефективні та легкі в підтримці комерційні боти.

## 2. Ключові функції

### Для користувача:
- **Інтерактивне меню:** Перегляд категорій та страв в один клік.
- **Персональний кошик:** Додавання страв, автоматичний підрахунок суми.
- **Покрокове замовлення:** Зручний процес оформлення замовлення (ім'я, контакт, адреса), що не втрачає дані при перезапуску бота.
- **Інформаційні розділи:** Швидкий доступ до контактів та допомоги.

### Для адміністратора:
- **Динамічне оновлення меню:** Можливість оновити все меню в боті **однією командою** (`/updatemenu`), яка завантажує дані безпосередньо з Google Таблиці.
- **Миттєві сповіщення:** Отримання детальної інформації про кожне нове замовлення в особисті повідомлення.

## 3. Технічний стек

| Компонент         | Технологія                                                              | Призначення                                                    |
|-------------------|-------------------------------------------------------------------------|----------------------------------------------------------------|
| **Мова**            | Python 3                                                                | Основна мова розробки.                                         |
| **Telegram API**    | `pyTelegramBotAPI`                                                      | Взаємодія з Telegram.                                          |
| **База даних**      | `SQLite`                                                                | Зберігання кошиків та стану оформлення замовлень (FSM).         |
| **Керування даними** | `Google Sheets` (експорт у CSV)                                       | Зовнішнє джерело даних для меню, що легко редагується.        |
| **Конфігурація**    | `python-dotenv`                                                         | Безпечне керування токенами та налаштуваннями.                 |
| **Оточення**        | `venv`                                                                  | Ізоляція залежностей проєкту.                                    |

## 4. Продемонстровані навички

### Архітектура та розробка:
- **Модульна структура:** Код розділено на логічні частини (`bot.py`, `database.py`, `keyboards.py`), що спрощує підтримку та розширення.
- **Створення FSM (Finite State Machine):** Реалізовано надійну машину станів для покрокового оформлення замовлення, яка зберігає прогрес у базі даних.
- **Розробка API для адміністратора:** Створено внутрішню команду для керування ботом.
- **Асинхронне виконання:** Оновлення меню виконується у фоновому режимі, не блокуючи роботу бота для інших користувачів.

### Робота з даними:
- **Проєктування та керування БД:** Використання SQLite для зберігання реляційних даних (користувачі, кошики, стани).
- **Інтеграція з зовнішніми сервісами:** Налаштовано отримання даних з Google Sheets.
- **Парсинг даних:** Обробка та валідація даних з CSV-файлу.

### Професійні практики:
- **Чистий код:** Застосовано принципи написання зрозумілого та добре структурованого коду.
- **Керування залежностями:** Використання `requirements.txt` та віртуального середовища.
- **Безпека:** Винесення чутливих даних (токен, ID) у `.env` файл, який ігнорується системою контролю версій (`.gitignore`).

## 5. Висновок

**Smakota Bot** — це готовий до впровадження, стабільний продукт, що демонструє комплексний підхід до розробки. Проєкт підтверджує навички, необхідні для створення сучасних Telegram-ботів для бізнес-задач, від архітектури до розгортання та підтримки.
