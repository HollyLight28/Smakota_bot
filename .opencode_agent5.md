# Agent 5: WebApp — перенести add-btn в card-body

## Проблема
Кнопка "+" (add-btn) знаходиться НА фото (position: absolute всередині .card-img-wrap) і перекриває край фотки. Вона кругла (border-radius: 50%).

## Що зробити

### 1. CSS — змінити .add-btn
- Позиція: absolute → відносно .card-body (не .card-img-wrap)
- Форма: овальна/pill (width: 36px, height: 28px, border-radius: 100px)
- Розташування: bottom: 12px, right: 12px всередині card-body

### 2. CSS — .card-body
- Додати `position: relative` (щоб add-btn позиціонувався відносно нього)
- Збільшити padding-bottom (щоб кнопка не вилазила)

### 3. CSS — .card-img-wrap
- Прибрати `position: relative` (воно більше не треба для add-btn)

### 4. HTML (renderMenu())
Поточна структура:
```html
<div class="card-img-wrap">
  <img ...>
  <button class="add-btn" onclick="addToCart(...)">+</button>
</div>
<div class="card-body">
  <p class="card-title">...</p>
  <p class="card-price">...</p>
</div>
```

Нова структура:
```html
<div class="card-img-wrap">
  <img ...>
</div>
<div class="card-body">
  <p class="card-title">...</p>
  <p class="card-price">...</p>
  <button class="add-btn" onclick="addToCart(...)">+</button>
</div>
```

### 5. Після змін
1. Запусти тест: `cd webapp && python3 -m http.server 8000` — перевір що сторінка відкривається
2. Зроби commit: `git add -A && git commit -m "fix: перенесено add-btn в card-body, овальна форма"`
3. Зроби push: `git push`

ВАЖЛИВО: Не змінюй логіку JavaScript. Тільки CSS + HTML структуру.
