# Smakota - Telegram Bot для доставки їжі

Сучасний Telegram-бот для оформлення замовлень доставки їжі з повноцінним функціоналом магазину.

## Функціонал

- 🍕 Розгалужене меню з кількома категоріями страв
- 🛒 Кошик з можливістю додавання/видалення товарів
- 💰 Автоматичний підрахунок суми замовлення
- 📝 Оформлення замовлення з ім'ям, контактом, адресою
- 📱 Сповіщення адміністратору про нові замовлення
- 💬 Коментарі до замовлень
- 📊 Зручний інтерфейс з кнопками та інлайн-меню

## Встановлення


## Як додати нові страви / змінити меню

Бот використовує вбудоване меню, яке можна легко модифікувати:

1. Відкрийте файл `bot.py`
2. Знайдіть функцію `load_menu()`
3. Додайте нові категорії або страви до відповідних масивів
4. Перезапустіть бота

Приклад додавання нової страви:
```python
{"id": 101, "name": "Нова страва", "price": 150, "category": "main_dishes", "description": "Опис нової страви"}
```

## Залежності

- Python 3.10+
- pyTelegramBotAPI
- python-dotenv

## Використання

1. Запустіть бота командою `python bot.py`
2. Відкрийте чат з ботом в Telegram
3. Використовуйте кнопки для навігації по меню
4. Додавайте страви до кошика
5. Оформлюйте замовлення через "Моє замовлення" → "Оформити замовлення"

## Підключення до реального меню

Для підключення до реального меню вашого закладу:

1. Замініть дані в функції `load_menu()` на ваші реальні страви
2. Можна організувати зчитування з JSON-файлу або бази даних
3. Для великих обсягів даних рекомендується використовувати базу даних (наприклад, SQLite)
