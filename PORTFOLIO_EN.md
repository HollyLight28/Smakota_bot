# Professional Portfolio: Food Delivery Telegram Bot "Smakota"

## Project Overview

**Smakota** is a modern Telegram bot for food delivery orders, designed for small businesses in the food industry. This is my first commercial project that demonstrates my skills in bot development, user experience design, and integration of various features into a unified system.

## Functionality

### Core Features:
- 🍕 **Extensive menu** with 6 categories of dishes (over 100 items)
- 🛒 **Shopping cart system** with add/remove functionality
- 💰 **Automatic calculation** of total order amount
- 📝 **Order processing** with name, contact, address, and comment
- 📱 **Admin notifications** for new orders
- 📊 **User-friendly interface** with buttons and inline menus

### Technical Features:
- Full integration with Telegram API
- FSM (Finite State Machine) for user state management
- Order management system
- Order data storage
- Error handling and recovery

## Technologies

- **Python 3.12**
- **pyTelegramBotAPI** - main library for Telegram API integration
- **python-dotenv** - for secure storage of configuration data
- **JSON** - format for menu data storage
- **OOP and procedural style** - to ensure code readability

## Architecture

The bot is built on a modular principle:
- Separate functions for menu, cart, and order management
- Clear separation of message and callback request handling logic
- State system for managing the order process
- Logging of all actions for further analysis

## User Experience

- Intuitive interface
- Clear navigation between sections
- Convenient order confirmation system
- Ability to cancel orders at any stage
- Summary messages before order confirmation
