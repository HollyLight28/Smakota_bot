## 1. ЗАГАЛЬНИЙ ОПИС ПРОЄКТУ

**Smakota Bot** — це Telegram-бот для сервісу доставки їжі "Смакота" (м. Рівне).  
Бот обслуговує повний цикл: від перегляду меню клієнтом до доставки кур'єром.

**Цілова аудиторія:**
- Клієнти (замовляють їжу)
- Адмін / Шеф (управляє бізнесом)
- Кур'єри (доставляють замовлення)
- Диспетчер (приймає замовлення по телефону)
- Наташа / Зал (обслуговує клієнтів у закладі)
- Кухня (список закупів для шефа)

**Кінцева мета Вови:** Зробити бота повністю автономним, щоб шеф міг ним користуватись без допомоги розробника.

#### 3.2 Порядок рефакторингу (кожен крок = окремий коміт)
1. Створити `bot/config.py` (винести BOT_TOKEN, ADMIN_ID, робочі години)
2. Створити `bot/__init__.py` (ініціалізація telebot)
3. Винести `handlers/start.py` (/start, визначення ролі)
4. Винести `handlers/client.py` (меню, кошик)
5. Винести `handlers/checkout.py` (FSM)
6. Винести `handlers/admin.py` (адмін-функції)
7. Винести `handlers/courier.py` (кур'єрські функції)
8. Винести `handlers/dispatcher.py` (ручне замовлення)
9. Винести `handlers/hall.py` (Наташа)
10. Винести `handlers/kitchen.py` (кухня)
11. Винести `handlers/callbacks.py` (всі callback_query)
12. Створити `bot/main.py` як нову точку входу
13. Видалити старий `bot.py`
14. Оновити `start_bot.sh` на `python3 -m bot.main`

## 4. ТЕСТУВАННЯ РОЛЕЙ

### Команди для перемикання ролей (на одному телефоні):
| Команда | Роль | Клавіатура |
|---------|------|------------|
| `/set_role_admin` | 👑 Адмін | Замовлення, Виручка, Моніторинг |
| `/set_role_courier` | 🛵 Кур'єр | Мої доставки, Мій звіт |
| `/set_role_client` | 👤 Клієнт | Меню, Кошик, Контакти |
| `/remove_me` | 🔌 Скинути все | — |

### Тестовий сценарій:
1. `/set_role_client` → Натисни "ВІДКРИТИ МЕНЮ" → Додай страви → "ОФОРМИТИ"
2. `/set_role_admin` → Побач нове замовлення → Призначай кур'єра
3. `/set_role_courier` → Побач замовлення → Натисни "ДОСТАВЛЕНО"
