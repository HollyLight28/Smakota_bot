# Project Brief: Smakota Bot

## Overview
Telegram bot for food delivery and courier management (CRM-lite).
Currently built with `pyTelegramBotAPI` (synchronous) and `sqlite3`.

## Core Features
- User: Menu, Cart, Checkout, History.
- Courier: Shift management, Active orders, Maps integration.
- Admin: Order assignment, Broadcasts, Menu updates.

## Tech Stack
- Python 3.x
- pyTelegramBotAPI (Telebot)
- SQLite
- Threading for limited concurrency
