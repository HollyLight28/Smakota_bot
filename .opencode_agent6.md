Задача: Почистити адмін-клавіатуру — прибрати кнопки що не працюють.

Проект: /home/aiuser/code/Smakota_bot/

## Контекст
- В keyboards.py функція get_admin_keyboard() має кнопки:
  - `📋 Нові замовлення` — працює ✅
  - `📊 Виручка за сьогодні` — НЕ працює (без підключення кур'єрів)
  - `📊 Моніторинг` — НЕ працює
  - `📣 Розсилка` — працює ✅

## Що зробити

### 1. Оновити get_admin_keyboard() в keyboards.py
Поточна:
```python
def get_admin_keyboard():
    keyboard = ReplyKeyboardMarkup(resize_keyboard=True)
    keyboard.row('📋 Нові замовлення', '📊 Виручка за сьогодні')
    keyboard.row('📣 Розсилка', '📊 Моніторинг')
    return keyboard
```

Нова:
```python
def get_admin_keyboard():
```
