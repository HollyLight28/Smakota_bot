# Agent 1: Нова БД — Продукти для закупів (shopping_products + цехи)

Проект: Smakota Bot (/home/aiuser/code/Smakota_bot)
Файли БД: database.py (SQLite через sqlite3)
Seed дані: shopping_products_seed.json (в корені проекту)

## Задача

Створити систему продуктів для списку закупів, розділену по цехах/департаментах.

### 1. Нова таблиця `shopping_departments`
```sql
id TEXT PRIMARY KEY,  -- 'meat', 'dairy', 'vegetables', 'dry', 'ready'
name TEXT NOT NULL,    -- '🥩 М'ясний цех'
description TEXT       -- 'Свіже м'ясо, птиця, риба, яйця, гриби'
```

### 2. Нова таблиця `shopping_products`
```sql
id INTEGER PRIMARY KEY AUTOINCREMENT,
name TEXT NOT NULL UNIQUE,   -- 'Куряче філе'
unit TEXT NOT NULL,           -- 'кг', 'шт', 'л', 'ящ', 'уп'
department_id TEXT NOT NULL,  -- FK -> shopping_departments.id
is_active INTEGER DEFAULT 1,
FOREIGN KEY (department_id) REFERENCES shopping_departments(id)
```

### 3. Функції в database.py

Додати функції:
- `setup_shopping_tables()` — створює таблиці (або додати в `setup_database()`)
- `seed_shopping_products()` — завантажує дані з shopping_products_seed.json в таблиці
- `get_departments()` — повертає всі цехи
- `get_products_by_department(department_id)` — повертає продукти цеху
- `add_shopping_product(name, unit, department_id)` — додати новий продукт
- `deactivate_shopping_product(product_id)` — деактивувати продукт
- `get_active_shopping_products()` — всі активні продукти

### 4. Сид-дані
Файл shopping_products_seed.json вже є в корені проекту. В ньому:
- 5 departments (meat, dairy, vegetables, dry, ready)
- ~100 продуктів

Функція seed_shopping_products() має:
1. Завантажити JSON
2. Створити department-и
3. Створити всі продукти
4. Викликатися при першому запуску (якщо таблиці пусті)

### 5. Старі таблиці
- `shopping_list` — залишити (потім будемо мігрувати)
- `shopping_templates` — залишити (потім видалимо)

### 6. Міграція
Додати в `setup_database()` виклик `setup_shopping_tables()` і `seed_shopping_products()`.
